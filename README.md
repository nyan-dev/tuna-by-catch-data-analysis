# Tuna Bycatch Data Analysis

Multi-phase analysis of Western and Central Pacific Fisheries Commission (WCPFC) tuna bycatch data using Jupyter Notebooks.

## Notebooks

| Notebook | Description |
|---|---|
| `WCPFC_NB1_Data_Diagnostics` | Phase 1-2: Data loading, cleaning, and diagnostics |
| `NB2_Phase3_Phase4_Transparent_Metrics` | Phase 3-4: Transparent metrics calculation |
| `NB3_Phase5_Phase6_Bayesian_Sensitivity` | Phase 5-6: Bayesian sensitivity analysis |

## Data Source

Data from the [Western and Central Pacific Fisheries Commission (WCPFC)](https://www.wcpfc.int/).

## Methods

- Data diagnostics and quality checks
- Transparent metrics calculation
- Bayesian sensitivity analysis

## Requirements

```
jupyter
pandas
numpy
matplotlib
```
